# Scrpits-infra-Automacao

🚀 **Scripts para Automação de Infraestrutura**

Este repositório contém scripts úteis para otimização e manutenção de infraestrutura de TI, incluindo reset de cache DNS, troca de IPv4/gateway e melhorias no desempenho do Windows.

## 📌 Funcionalidades
- 🔄 Reset de cache DNS e flush de conexões de rede
- 🌐 Automação de troca de IP e gateway
- ⚡ Otimizações para desempenho do Windows

## 📂 Estrutura do Repositório
```
/infra-automation-scripts
│── scripts/
│   ├── reset_dns.bat
│   ├── change_ip.ps1
│   ├── optimize_windows.reg
│── README.md
```

## 🛠️ Como Usar
- Execute `reset_dns.bat` para limpar o cache DNS.
- Utilize `change_ip.ps1` para trocar automaticamente seu IPv4 e gateway.
- Aplique `optimize_windows.reg` para otimizar o desempenho do Windows.

## ⚠️ Aviso
Utilize os scripts com cautela e apenas se souber o que está fazendo. Sempre teste em um ambiente seguro antes de aplicar em produção.
